# Vår techstack

| Område | Teknik |
| --- | --- |
| **Frontend** | React, JavaScript |
| **Routing** | React Router |
| **Styling** | Vanlig CSS |
| **Backend** | Node.js, Express |
| **API** | REST (JSON), Fetch |
| **Databas** | PostgreSQL |
| **Auth** | JWT |
| **Lösenord** | bcrypt |
| **Versionshantering** | Git och GitHub |
| **API-test** | Postman |
| **Databas (GUI)** | pgAdmin (eller annat om ni komemr på nåt)|
| **Drift** | Render |
| **Projekt** | GitHub Projects |

**Inte med i stacken:** Tailwind, Bootstrap, Material UI, styled-components, extra frontend-/backend-ramverk, intern chatt, intern betalning.  (för atty dessa ska inte implementeras, håller till minimal eller minsta MVP för att hinna med en hel fungerande)
