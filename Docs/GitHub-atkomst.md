# GitHub: 403 vid push

**Orsak:** Se till att du är inloggad och har skrivrättighet till `Andreas00H/BorrowNotBuy`.

## Pusha till egen fork (remotes redan inställda)

1. Forka på GitHub: [Andreas00H/BorrowNotBuy](https://github.com/Andreas00H/BorrowNotBuy) → **Fork**
2. Pusha: `git push -u origin main`
3. Öppna PR från `ErnestIssa/BorrowNotBuy` → `Andreas00H/BorrowNotBuy`

| Remote | URL | Användning |
| --- | --- | --- |
| `origin` | `ErnestIssa/BorrowNotBuy` | **push** |
| `upstream` | `Andreas00H/BorrowNotBuy` | **pull** (teamets repo) |

Hämta teamets ändringar: `git fetch upstream` → `git merge upstream/main`
